# Neutze's Macros

Class macros for **World of Warcraft: Forever**, one click each.

Open `/nm` (or Options > AddOns > Neutze's Pantry > Neutze's Macros) and pick your spec. You get a grid of spell buttons. Click one and its macro is created on this character, or updated if it already exists, and put on your cursor so you can drop it on a bar. **Create / update all** does the whole spec in one go.

- **One ability per macro.** Where a stance or form is needed, the macro switches first, then uses the ability. In WoW Forever that takes two presses.
- Melee abilities start auto-attack. Caster spells don't, so wanding isn't interrupted.
- Mouseover where it helps: `[@mouseover,harm,nodead][harm,nodead]` for attacks, `[@mouseover,help,nodead][help,nodead][@player]` for heals.
- Presets for all 9 classes and their specs. Warrior includes the stance-dance set from Cynara's *UPDATED Warrior Macros (WoW Forever)*: focus Pummel, Death Wish and Recklessness with trinkets, Challenging Shout with Limited Invulnerability Potion, Intimidating Shout with stop-attack, auto Shoot/Throw, Stop Queue.
- Macros are per character. Free character macro slots are checked first.

**Requires [Neutze's Pantry](https://github.com/neutze/wow-neutze-pantry)**: install it too. This add-on's options page sits under Neutze's Pantry.

Part of the **Neutze's** suite: [Pantry](https://github.com/neutze/wow-neutze-pantry) · [Companion](https://github.com/neutze/wow-neutze-companion) · [Stable](https://github.com/neutze/wow-neutze-stable)

## Install
CurseForge app, or download `NeutzeMacros-v0.0.1.zip` from [Releases](https://github.com/neutze/wow-neutze-macros/releases) into `World of Warcraft/_forever_/Interface/AddOns/`.
